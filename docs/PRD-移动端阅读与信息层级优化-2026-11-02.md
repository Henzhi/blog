# PRD：移动端阅读与信息层级优化

- 日期：2026-11-02
- 站点：`https://henzhi.github.io/blog/`
- 状态：已完成（本地构建验证，未发布）
- 优先级：P0 内容可完整查看 > P1 移动阅读与浏览效率 > P2 信息去重 > P3 视觉微调

## 1. 问题背景

当前博客的桌面三栏、中文长文排版和亮暗主题已经稳定，但真实移动视口回归暴露出四类问题：

1. **表格被裁切**：390px 下，长文表格右边界约为 400px，第四列无法完整看到；外层 `#swup-container` 的 `overflow-hidden` 会掩盖溢出，而不是提供滚动。
2. **代码块滚动约束不够明确**：长代码依赖 Expressive Code 默认样式，需保证只在代码容器内部横向滚动，不撑宽正文或整页。
3. **小屏信息结构拥挤**：根字号为 14px 时，文章元信息约 11.4px；首页列表标题和日期同排，长标题断行不稳定；归档页移动标题被单行省略且缺少明确页头。
4. **信息重复与细节不一致**：首页“最新文章”和侧栏“最近更新”展示同一批文章，归档页也重复；首页标题/摘要层级可再拉开，TOC 悬浮按钮可进一步统一尺寸与视觉。

基线实测覆盖首页、长文页、归档页，亮/暗主题及 390 / 768 / 1024 / 1440px 视口；整页无横向滚动，但表格内容存在局部裁切。

## 2. 改进目标

- 移动端所有表格均可通过自身容器完整查看，不能出现不可达列。
- 代码块横向滚动限制在自身区域，滚动前后页面宽度保持不变。
- 提升移动正文、元信息和列表扫读体验，标题不再与日期争抢横向空间。
- 归档页在小屏上能看清页面定位、结果数量和文章完整主题。
- 首页与归档页移除重复“最近更新”，同时保持文章页等页面的侧栏能力及 swup 换页一致性。
- 保持现有技术阅读风格和桌面布局，不用重新设计换取局部优化。

## 3. 非目标与约束

- 不修改路由、文章内容、分类数据、搜索、RSS、部署方式和 GitHub Pages `base`。
- 不改变桌面三栏栅格、正文宽度、目录 rail/drawer 断点及折叠偏好。
- 不新增字体、主题色、Banner、卡片、厚阴影或装饰性组件。
- 不把长表格强行压缩为小字号，不把代码改为自动换行。
- 不删除全站“最近更新”；仅在首页和归档页隐藏，文章页、关于页等保持原样。

## 4. 设计规范

### 4.1 Purpose Statement

面向在手机上阅读技术长文、扫读文章列表的访客，优先保证内容可达、文字可读和结构可扫。此次是既有设计系统内的收口，不是视觉重做。

### 4.2 Aesthetic Direction

**Editorial / magazine（编辑体技术阅读）**：以文字层级、细分隔线和留白建立秩序，保留非对称桌面栏结构。

### 4.3 Color Palette

沿用 `src/styles/variables.styl` 的品牌令牌，不新增颜色：

- `--page-bg: oklch(0.95 0.008 250)` / 暗色 `oklch(0.145 0.008 250)`
- `--primary: oklch(0.52 0.15 250)` / 暗色 `oklch(0.72 0.15 250)`
- `--card-bg: white` / 暗色 `oklch(0.205 0.010 250)`
- `--border-subtle` 与现有文字透明度阶梯

既有品牌字体和色彩约束覆盖通用 UI 模板规则；不引入新色板。

### 4.4 Typography

- 拉丁/数字：继续使用 `Inter Variable`。
- 中文：继续使用现有系统中文字体栈。
- 代码：继续使用 `JetBrains Mono Variable`。
- 移动长文正文约 16.6px / 1.8；桌面保持 18px / 1.75。
- 移动元信息不低于 12px；桌面元信息保持 13px。
- 首页文章标题移动约 17.5px、桌面 19px，字重 600；摘要保持次级色，最多两行。

### 4.5 Layout Strategy

- 保留桌面 `目录 / 正文 / 右侧栏` 非对称三栏和首页 `主栏 / 右栏`。
- 小屏只调整组件内部信息顺序：标题独占一行，日期进入元信息区域；归档日期置于标题上方。
- 表格和代码使用局部滚动容器，绝不要求整页横向滚动。

## 6. 交互与视觉要求

### P0：表格与代码

- 表格外层：`max-width: 100%`、`overflow-x: auto`、触摸惯性滚动、横向滚动链隔离。
- 滚动区域可键盘聚焦，`focus-visible` 有清晰轮廓；屏幕阅读器获得“表格，可横向滚动”的区域说明。
- 表格保持现有细线视觉，不增加外框卡片。
- 代码块 `pre` 自身横向滚动；长行不折行，代码块最大宽度不超过正文。
- 表格/代码内部可以存在 `scrollWidth > clientWidth`，但文档根节点不得因此变宽。

### P1：移动排版、列表与归档

- `<768px` 长文正文约 16.6px，行高约 1.8；桌面字号行高不变。
- 元信息移动约 12.25px，避免 11px 小字；桌面保持原值。
- `<640px` 首页文章标题占满可用宽度；日期与字数/时长组成底部元信息，不再固定在标题右侧。
- 标题允许自然两行，使用平衡换行；摘要保持最多两行，桌面摘要最大宽度 44rem。
- 归档页显示“归档”和当前结果数量；筛选后数量同步更新。
- `<640px` 归档日期在标题上方，标题最多两行且不省略；桌面继续保持原有密排单行形式。

### P2：侧栏去重

- 首页 `/blog/` 和归档 `/blog/archive/`（含查询参数）不显示“最近更新”。
- 文章、分类、关于等页面保持显示。
- 通过 swup 在首页、归档和文章之间切换时，显隐必须与当前 URL 一致，无整页刷新依赖。

### P3：视觉微调

- 首页标题略增强，摘要行长收敛，不增加新的装饰。
- TOC 抽屉悬浮按钮为 44×44px，保留原位置逻辑、图标和 48px 左右的触摸舒适区，使用现有卡片色、边线色与阴影变量。
- 桌面 rail 目录和收起标签不受影响。

## 8. 回归检查项

### 8.1 静态与构建

- `npm run lint`
- `npx astro check`
- `npm run build`
- 检查构建产物中的表格 wrapper、子路径资源和 Pagefind 索引。

### 8.2 关键页面

- 首页：Hero、简介展开、文章链接、分类入口、搜索、主题切换。
- 长文：标题锚点、表格、代码复制、TOC rail/drawer、目录点击与滚动高亮、上/下一篇。
- 归档：直接访问、分类/标签查询、清除筛选、空结果。
- 分类与关于：侧栏“最近更新”保留，正文宽度正常。
- 亮/暗主题：表格焦点、代码滚动条、悬浮按钮、归档文字层级。

### 8.3 视口与导航

- 390×844：主要移动验收。
- 768×1024：单栏与移动/平板导航衔接。
- 1024×900：双栏与目录抽屉。
- 1440×1000：桌面三栏与目录收起/展开。
- 1920×1080：最大宽度与居中不回归。
- swup：首页 → 文章 → 归档 → 关于，检查侧栏、TOC、控制台和资源加载。

### 8.4 既有自动回归

- 运行 `python scripts/toc-check.py`，109 项目录/布局断言必须全部通过。
- 输出写文件后再筛选，不通过管道提前截断，避免 SIGPIPE 造成假失败。
